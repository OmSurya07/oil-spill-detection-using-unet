#How to Run the Project (Google Colab)

Download the Refined Deep-SAR Oil Spill Dataset from Zenodo.

Upload the downloaded ZIP file to your Google Drive.

Open the notebook from the notebooks folder using Google Colab.

Mount your Google Drive when prompted.

Update the dataset ZIP path in the notebook to match its location in your Drive, if required.

Run the notebook cells sequentially.

The notebook handles dataset extraction, preprocessing, U-Net model training, and evaluation.

Note: Google Colab is the recommended environment. GPU acceleration can be enabled through Runtime → Change runtime type → T4 GPU (when available).
